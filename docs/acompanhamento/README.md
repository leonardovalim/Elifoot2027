# Acompanhamento do projeto

Este diretório é o ponto de consulta online do andamento do Mestres do Esporte.

- [Status atual](./STATUS.md): o que já foi concluído e o que ainda falta.
- [Plano técnico detalhado](../superpowers/plans/2026-11-19-pixel-art-vertical-slice.md): decisões e tarefas da fatia atual.
- [Especificação visual](../superpowers/specs/2026-11-19-pixel-art-vertical-slice-design.md): direção de pixel art, layout e UX.

## Como usar este acompanhamento

1. Comece pelo `STATUS.md`.
2. Marque as próximas tarefas conforme forem implementadas.
3. Registre decisões de produto ou plataforma no próprio status antes de iniciar uma nova frente.

O estado deste diretório acompanha a branch do PR desta entrega.
